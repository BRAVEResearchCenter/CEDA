# Karpov, Kleinschmidt, Heyn, & Herringa, 2026

This folder contains the code used in the following paper: 
Karpov, G., Kleinschmidt, B.W., Heyn, S.A., Russell, J.D., & Herringa, R.J. (under review). Differential adolescent neurodevelopment of emotion regulation across internalizing psychopathology and childhood adversity

### Overview of files
1. `LinearMixedEffects_Group-Analysis.R` - R code detailing the main analysis comparing healthy controls and youth with internalizing disorders, including any data transformations and the statistical model. Mplus software runs the models specified in the code.

2. `LinearMixedEffects_Adversity-Analysis.R` - R code detailing the post-hoc analysis on the moderating effect of adversity exposure in youth with internalizing disorders. Includes any data transformations and the statistical models. Mplus software runs the models specified in the code.

3. `LinearMixedEffects_Decomp-Analysis.R` - R code detailing the decomposition analysis run to describe individual stimulus valence effects across negative vs neutral stimuli. Mplus software runs the models specified in the code.

4. `ROIs_atlas_Schaefer2018_desc-400Parcels7Networks.txt` - List of all 126 frontal lobe regions of interest as taken from the Schaefer Atlas (Schaefer et al., 2018), including the atlas index number. Accessed from: https://github.com/ThomasYeoLab/CBIG/tree/master/stable_projects/brain_parcellation/Schaefer2018_LocalGlobal/Parcellations/MNI
> Schaefer A, Kong R, Gordon EM, Laumann TO, Zuo XN, Holmes AJ, Eickhoff SB, Yeo BTT. Local-Global parcellation of the human cerebral cortex from intrinsic functional connectivity MRI. Cerebral Cortex, 29:3095-3114, 2018.
